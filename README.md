# Pokémon Price Tracker

Module TypeScript/Node.js pour suivre les ventes eBay de cartes Pokémon japonaises.

Fonctions prévues : recherche par référence (`040/141`), médiane en JPY, conversion en EUR au taux actuel, séparation raw/gradées et historique local.

## Lancer

```bash
npm install
cp .env.example .env
npm run dev
```

Les clés eBay restent uniquement dans `.env` et ne doivent jamais être commitées.
